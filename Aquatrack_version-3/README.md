# AquaTrack version 3

Start with the repository’s **[complete setup and user guide](../README.md)**. It covers Windows, Linux/macOS, NetBeans, database creation, first-owner setup, all application screens, backups, and troubleshooting.

- Java entry point: `aquatrack.Main`
- JDK: 17 or later
- Database: MySQL 8.0.16+ or MariaDB 10.4+
- Fresh database setup: [`sql/schema.sql`](sql/schema.sql)
- First owner setup: [`sql/bootstrap-owner.sql`](sql/bootstrap-owner.sql), using a password hash generated by `aquatrack.util.PasswordUtil` as explained in the guide
- Connection settings: [`src/aquatrack/db/Database.java`](src/aquatrack/db/Database.java)

There is no default AquaTrack login. The SQL scripts contain no business data and do not migrate an existing database. Build the current source before launching.
